## 📊 Michele Galeotto 風格分析

### 個人背景
- **身份**：Creative Director | Video Production at goodtakesonly
- **地點**：香港
- **粉絲**：4,553 個關注者
- **專長**：視頻製作、創意方向、品牌內容

### 帖文特徵

#### 1. **內容主題**
- ✅ **項目案例展示**（Simpson Marine、Sanlorenzo Yachts、Axopar Boats）
- ✅ **行業思考**（AI 對創意的影響、創意工作室的挑戰）
- ✅ **個人故事**（5 年創業經驗、淡季反思）
- ✅ **視頻內容為主**（展示作品、幕後花絮）

#### 2. **文案風格**
- **開場方式**：直接、故事性強
  > "Last month, we partnered with Simpson Marine Limited for a series of dynamic projects..."
  > "We're coming up to our 5th year in business, and one thing we've noticed..."

- **語氣**：專業但親切、有個性
  - 用「we」而非「I」（團隊感）
  - 分享真實挑戰（淡季、AI 威脅）
  - 帶有思考深度

- **長度**：中等長度（200-400 字）
  - 不過度冗長
  - 清晰段落分隔
  - 易於掃讀

#### 3. **視覺策略**
- 高質量視頻為主
- 品牌合作方的 logo 提及
- 場景豐富（戶外、活動、工作現場）
- 專業但不過度商業化

#### 4. **互動策略**
- 帖文中提及具體品牌（Simpson Marine、Axopar）
- 分享真實數字和時間線
- 邀請思考（「你注意到了嗎？」的隱性邀請）
- 少用 CTA，讓內容自己說話

- **互動率高**：24.42% vs 文字帖 6.67%

## 🎨 JD Studio 專屬輪播公式

### 核心策略
**結合 Michele 的「項目 + 思考」風格 + 商業數據清晰度（吸引 brand／市場部買家）**

### 輪播類型 A：「項目案例 + 幕後故事」
**適用於：婚禮、活動、商業攝影**

#### 結構（5-7 張幻燈片）
```
Slide 1: 封面 - 引人入勝的問題或陳述
"這場婚禮，我們如何在 8 小時內拍出 2000 張照片？"

Slide 2: 場景設置 - 背景故事
"新娘想要自然、不擺拍的風格。
天氣：陰天 + 突然下雨
挑戰：光線不足 + 時間緊張"

Slide 3: 我們的方法 - 技術 + 策略
"✓ 3 台相機 + 2 位攝影師
✓ 預設的 Lightroom 配置
✓ 實時溝通系統"

Slide 4: 幕後花絮 - 真實時刻
"最瘋狂的一刻：新娘爸爸在儀式中哭了，
我們捕捉到了他摘下眼鏡的那一秒。
這張照片後來成了他們最珍惜的回憶。"

Slide 5: 結果 - 數字 + 情感
"✓ 交付 150 張精選照片
✓ 新娘：『你們不只拍了我的婚禮，
你們拍了我們的故事』"

Slide 6: 核心洞察 - 思想領導
"攝影不是技術，是信任。
當新娘相信你會捕捉她的真實時刻，
她就會放下防備。
那時，魔法就發生了。"

Slide 7: CTA - 邀請互動
"你的婚禮故事是什麼？
評論下方 👇"
```

#### 文案風格示例
```
開場：
"上週六，我們見證了一場雨中婚禮。
新娘說『我不要完美，我要真實』。
這改變了我們整個拍攝方式。"

中段：
"我們放下了所有的『應該』：
❌ 應該用三腳架
❌ 應該等待完美光線
❌ 應該按照計劃拍攝

✅ 我們跟隨故事
✅ 我們擁抱混亂
✅ 我們捕捉靈魂"

結尾：
"最後一張照片是新娘和她媽媽在雨中擁抱。
沒有化妝、沒有擺拍、沒有完美。
但這是我見過最完美的照片。"
```

### 輪播類型 B：「攝影教育 + 行業洞察」
**適用於：建立思想領導力、吸引潛在客戶**

#### 結構（5-6 張幻燈片）
```
Slide 1: 引人入勝的標題
"為什麼你的婚禮照片看起來『廉價』？
（提示：不是相機的問題）"

Slide 2: 打破迷思
"❌ 常見誤解：好照片 = 好相機
✅ 真相：好照片 = 好光線 + 好故事 + 好時機"

Slide 3: 具體例子
"同一場景，3 個不同的攝影師：
- 攝影師 A：平淡無奇（錯誤的角度）
- 攝影師 B：技術完美但無靈魂（過度編輯）
- 攝影師 C：故事感十足（正確的時刻）"

Slide 4: 你應該做什麼
"拍攝前問自己：
1. 這個時刻的『故事』是什麼？
2. 光線如何塑造情感？
3. 我想讓觀看者感受到什麼？"

Slide 5: 實踐建議
"下次拍攝時，試試這個：
• 停止擺拍，開始觀察
• 停止尋找完美光線，開始利用現有光線
• 停止拍照，開始講故事"

Slide 6: CTA
"你最喜歡的婚禮照片是什麼時候拍的？
是擺拍還是自然時刻？
分享你的故事 👇"
```

## 🎯 JD Studio 輪播發佈策略

### 發佈時間表
- **每週 2-3 次**（不要過度）
- **最佳時間**：
  - 週二-週四：上午 8-9 點 / 下午 12-1 點
  - 週五：下午 4-5 點（週末計劃時間）

### 輪播主題輪轉
```
每週固定 2 篇（教育／洞察已停產）：
週二 08:00 HKT — 項目案例 + 幕後故事（展示真實工作流程）
週五 16:00 HKT — 數據 + 視覺化（吸引商業客戶）
```

### 設計要點
- **第一張幻燈片**：大膽、清晰、引人入勝
- **字體**：簡潔、易讀（避免花哨字體）
- **顏色**：JD Studio 品牌色 + 黑白對比
- **每張幻燈片**：一個想法，不要過度擁擠
- **移動優化**：1080×1080px 正方形格式

### 文案原則
- ✅ **故事優先**：「發生了什麼」比「我是誰」更重要
- ✅ **具體數字**：「150 張照片」比「很多照片」更有力
- ✅ **真實挑戰**：分享困難，不只分享成功
- ✅ **邀請互動**：每張輪播都以問題結尾
- ✅ **簡短有力**：每張幻燈片 1-3 句話
